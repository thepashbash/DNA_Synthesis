#Описание.
	Программа для демонстрации использования многопоточной модели «производитель-потребитель»  для программной симуляции одного из этапов процесса внутриклеточного синтеза белка из аминокислот.
	Программа принимает один необязательный параметр командной строки при запуске: значения дополнительной задержки при работе любого потока в милисекундах. Если параметр не задан, программа запускается со стандартным значением задержки 2000 мс (2 сек.).
	После запуска параметр задержки можно менять в процессе работы нажатием на клавиатуре стрелок управления курсором вверх и вниз. Так же при работе программы можно приостанавливать работу всех потоков клавишей пробел, и принудительно менять статус работы симулятора клавишей Ввод. При нажатии клавиши Escape программа завершает свою работу предварительно восстановив старые значения адресов векторов прерываний системного таймера и клавиатуры.

#Алгоритм выполнения программы.
	В рамках модели производитель – потребитель программа формирует четыре потока производителей (номера 1-4) и четыре потока потребителей (номера 5-8).
Каждый поток – производитель в процессе работы генерирует свой тип нуклеотида (A,T,G,C)  с порядковым номером и складывает его в буфер со структурой – стек глубиной 10. Например поток 3 - производитель гуанина, он генерирует в течении отведенного ему времени несколько кодов: G001, G002 и складывает их в буфер.
	Потребители берут из вершины стека буфера нуклеотиды и собирают из них пары оснований. Каждый потребитель может собрать одну из четырех возможных пар (A-T, T-A, G-C, C-G). Каждый тип потребителя может взять только подходящий кирпичик. Например потребитель G-C при первом вызове может присоединить два из четырех типов нуклеотида: гуанин (G) или цитозин (C), а когда будет заполнена одна из половин пары, тогда подойдет только один оставшийся вариант. 
	После завершения формирования пары потребитель переносит ее в начало очереди – нити ДНК, пара потребителя очищается и потребитель готов к сборке следующей пары.
Потребители берут стройматериалы из буфера в любом случае, если взятый кирпич не подходит, он его отбрасывает и уменьшает приоритет производителя данного типа кирпичей, если подходит, то потребитель встраивает его в свою пару и увеличивает приоритет данного производителя.
	После заполнения очереди пар оснований длиной 6 последние три пары с конца очереди переносятся в поле сборки текущего кодона, после чего эти три пары оснований подвергаются процедуре транскрипции, при которой правая часть пары оснований ДНК переносится на РНК, а  основание тимин заменяется на урацил, в результате чего получается тройка оснований называемой кодоном. 
Пример: отрезок нити ДНК A-T T-A G-C преобразуется в кодон AUG 
	Кодон, состоящий из трех элементов четырех видов имеет 4^3=64 комбинации, из которых 61 комбинация кодирует определённые аминокислоты , а 3 оставшихся кодона (UGA, UAG и UAA) сигнализируют об остановке трансляции полипептидной цепи и называются стоп-кодонами.
Стартовым кодоном у эукариотических организмов является триплет AUG в мРНК, кодирующий метионин.
Последовательность кодонов в гене определяет последовательность аминокислот в полипептидной цепи белка, кодируемого этим геном.[1]
	Процедура обработки кодона расшифровывает его тип и отслеживает управляющие старт и стоп кодоны.
	При запуске программа имеет статус ожидания стартового кодона.
	Когда стартовый кодон случайным образом создается программа переходит в состояние синтеза белка и добавляет в цепь синтеза белка аминокислоты, соответствующую сформированному кодону.
	В состоянии активного синтеза если будет случайно собран один из трех стоп кодонов, программа переходит в состояние окончания синтеза и отображает синтезированную полипептидную цепь белка и количество аминокислот в цепи.
При этом процесс генерирования новых кодонов продолжается, но в синтезе они уже не учувствуют. Данный процесс можно приостановить нажатием клавиши пробел.
Состояния ожидания стартового кодона и активного синтеза можно принудительно перешагнуть нажатием клавиши Ввод. Из состояния завершения синтеза можно выйти только перезапуском программы.
